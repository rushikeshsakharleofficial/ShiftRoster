# Chat Encryption, Media, and Purging Implementation Plan (2026-04-17)

> **For Gemini:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement E2EE with recovery mnemonics, admin-controlled purging, disappearing messages, and rich media (GIFs/Emojis). All features are guarded by Admin-level toggles.

**Architecture:** 
- **Encryption:** Client-side E2EE (RSA-OAEP/AES-GCM). Includes a BIP39-style 12-word mnemonic for private key recovery (stored locally in IndexedDB).
- **Admin Control:** New `org_settings` flags: `enable_chat_encryption`, `enable_gifs`, and `enable_user_disappearing_mode`.
- **Media:** `emoji-mart` for local emojis; Giphy API via `REACT_APP_GIPHY_API_KEY` in `.env`.
- **Purging:** MongoDB TTL indices + FastAPI background tasks for "Housekeeping".

**Tech Stack:** Web Crypto API, BIP39 logic, MongoDB TTL, Giphy API, FastAPI.

### Task 1: E2EE with Mnemonic Backup (Free)

**Files:**
- Create: `frontend/src/lib/crypto.js` (Key gen, AES wrappers, Mnemonic logic)
- Modify: `frontend/src/pages/ChatPage.js` (Encryption lifecycle)
- Modify: `frontend/src/pages/SettingsPage.js` (Show/Download Mnemonic backup)

**Steps:**
1. Use a JS-based BIP39 library (free) to generate a 12-word phrase.
2. Derive the RSA-OAEP key pair from this seed.
3. Store the seed in IndexedDB; provide a "Download Paper Key" button in Settings for recovery.

### Task 2: Encrypted File Attachments

**Files:**
- Modify: `frontend/src/lib/crypto.js` (`encryptFile` / `decryptFile`)
- Modify: `frontend/src/pages/ChatPage.js` (Update upload/download logic)

**Steps:**
1. Encrypt file chunks locally using AES-256-GCM.
2. Upload encrypted blob; store the encrypted symmetric key in the message metadata.

### Task 3: Admin Purging & User Disappearing

2. User: Set "Disappearing Timer" (7d, 30d, 3mo, 6m, 1y, Custom) — only if Admin enabled the flag.
